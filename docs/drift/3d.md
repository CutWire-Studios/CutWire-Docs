# 3D

Drift's timeline is three-dimensional. A flat clip can be tilted in space, a
`.glb` model or Gaussian splat can play in the same cut as your footage, and a
scene camera can move through all of it on its own lane.

The **3D** workspace (under **Studio** in the workspace switcher) opens the 3D
Outliner, Viewport, Transform, Camera, and View & Lights panels around the
preview.

## Making a clip 3D

Select a clip and open the **Transform** tab. A flat clip reads *This clip is
flat. Make it a 3D layer to rotate it and move it in depth.* — press **Make 3D
layer**.

| Control | What it does |
|---|---|
| **Position (px)** | X, Y, and Z. Z moves the clip in depth. |
| **Anchor point (px)** | The point it rotates and scales about. |
| **Rotation (°)** | Pitch, yaw, and roll. |
| **Scale / depth scale (%)** | Size, and how much depth affects it. |
| **Perspective** | Field of view for the clip's own view, used when there is no scene camera. |
| **Occlude by depth** | Let depth decide what covers this clip, instead of its track position. |

Each row has its own reset, and a keyframe toggle to **Add** or **Remove
keyframes at the playhead**.

:::note
**Occlude by depth** only sorts clips that also have it on; everything else still
draws in track order. It needs the **Normal** blend mode — the others read the
canvas behind the clip, which depth cannot sort.
:::

**World and local position** switches the readout between scene coordinates and
the object's own.

## 3D models and splats

Drop a model onto the timeline and the **3D Model** tab appears.

Supported files: `.glb`, `.sog`, `.ply`, `.zip`, `meta.json`, `lod-meta.json` —
3D models and Gaussian splats.

| Control | What it does |
|---|---|
| **Replace model…** | Load another model or splat; position, length, pose, and lighting stay. |
| **Animation** | Which of the file's animations plays. |
| **After the end** | *Hold last frame*, *Loop*, *Ping-pong*, or *Hide*. |
| **Start offset** | Where in the animation the clip begins. |
| **Model scale** / **Depth scale** | Size of the model, and how depth scales it. |

Position, size, rotation, anchor point, and depth occlusion live on the
**Transform** tab.

### Lighting

A model carries its own lights. Drag them in the 3D view, or set them in
**Lighting** on the model tab — they move and scale with the clip, and turning
the model turns it under them.

| Control | What it does |
|---|---|
| **Ambient** | Overall fill light. |
| **Light 1–n** | Colour, plus **Left / right**, **Up / down**, and **Near / far** placement. |
| **Brightness** | Light intensity. |
| **Reach** | How far the light carries. |
| **Spot angle** | Cone width for a spot. |
| **Aim left / right**, **Aim up / down** | Where the spot points. |

## The 3D viewport

The **3D Viewport** panel (and the preview's 3D mode) is a free view of the
scene with gizmos for placing things.

### Views

| View | Key |
|---|---|
| **Front** / **Back** | `Num+1` / `Ctrl+Num+1` |
| **Right** / **Left** | `Num+3` / `Ctrl+Num+3` |
| **Top** / **Bottom** | `Num+7` / `Ctrl+Num+7` |
| **Orbit** left / right / up / down | `Num+4` / `Num+6` / `Num+8` / `Num+2` |
| **Dolly** in / out | `Num++` / `Num+-` |
| **Orthographic** | `Num+5` |
| **Look through the scene camera** | `Num+0` |
| **Frame the selection** | `F` or `Num+.` |
| **Frame everything** | `Home` |
| **Reset the view** | `Shift+Home` |

### Gizmos

| Gizmo | Key |
|---|---|
| **Move** | `T` |
| **Rotate** | `R` |
| **Scale** | `E` |
| **Cycle world / local / view axes** | `Shift+T` |

**World** axes follow the scene, **Local** axes follow the selected object
(scale always follows the object's own edges), and **View** axes follow the
screen.

### Fly mode

`Shift+F` enters fly mode: *W/A/S/D move · Q/E down/up · Shift faster · Wheel
speed · Esc or click to finish.* Move the pointer to the centre ring to start
steering.

### Grid and snapping

**View & Lights** holds the viewport's own preferences:

| Control | What it does |
|---|---|
| **Show grid** | The floor grid drawn under the scene. |
| **Grid size** | Spacing between lines. `0` picks one from the canvas size. |
| **Move / Rotation / Scale step** | Gizmo drags are free; hold `Ctrl` to move, turn, and scale in these steps, and `Shift` for fine control. `0` turns a step off. |
| **Editor field of view** | How wide the editor view is. |
| **Navigation scheme** | **Blender** — middle-drag orbits, `Shift` pans, `Ctrl` dollies. **Maya** — `Alt` with the left, middle, or right button orbits, pans, or dollies. |
| **Orbit around selection** | Orbit about the selected clip's centre instead of the view's target. |
| **Orthographic** | Draw the viewport without perspective. |

## The scene camera

Without a camera every clip is seen through its own **Perspective**. The
**Camera** panel adds one:

| Control | What it does |
|---|---|
| **Add camera** | Adds a camera clip at the playhead, for a camera cut, or a camera track with a camera clip over the whole sequence. |
| **Lock camera to view** | Navigating while looking through the camera moves the camera. |
| **Align the scene camera to the view** | Snap the camera to the viewport's current view. |

Cameras are clips, so a camera move is keyframed like anything else — dolly,
crane, and orbit all live on the camera's own lane. A camera has no transform of
its own; its position, rotation, and zoom are in the Camera panel.

## 3D Outliner

Lists the **Cameras**, **Models**, and **Layers** present at the playhead, with
**Show this clip's track** and **Hide this clip's track** on each row. With
nothing in the scene it reads *No cameras, models or 3D layers at the playhead.*

## Procedural 3D

The **Procedural** workspace generates 3D content from code. It pairs the
**Procedural Code** editor with **Procedural Parameters** and a **Procedural
Console**:

| Control | What it does |
|---|---|
| **Pick a package** | The package to edit. Selecting a procedural clip opens its package. |
| **New** | Create a minimal procedural package. |
| **Duplicate to edit** | Copy a built-in package to your own and edit the copy. |
| **Apply** (`Ctrl+S`) | Validate and install the package, then refresh the preview. |
| **Check** | Validate the edits without installing them. |
| **Revert** | Discard edits and reload from disk. |
