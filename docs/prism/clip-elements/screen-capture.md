# Screen capture

A **Screen Capture** element shows a live feed of an entire display. Use it to
project a presentation, a browser, a game, or anything else running on your
computer.

**Add it:** **Add Element → Screen Capture…**.

## What it can do

- Mirror a whole monitor live to either deck.
- **Transform and position** on a canvas via the card's inline **Transform**
  controls — shrink the desktop into a frame and surround it with overlays.
- Crossfade between a screen and any other source.

## Screen vs. window

- **Screen Capture** grabs an entire display — everything visible on that
  monitor.
- [Window / Tab capture](./window-capture) grabs just one application window, so
  notifications and other windows never sneak into shot.

Pick whichever matches what you want the audience to see.

> On Linux, screen capture uses the system's screen‑sharing mechanism, so you may
> be asked to pick the display or grant permission the first time.
