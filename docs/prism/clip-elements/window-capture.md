# Window / Tab capture

A **Window / Tab** element shows a live feed of a single application window rather
than the whole screen. Use it when you want one app on screen and nothing else —
a slide deck, a scoreboard app, a browser tab — without the risk of a stray
notification or another window appearing.

**Add it:** **Add Element → Window / Tab…**.

## What it can do

- Stream one chosen window live to either deck.
- **Transform and position** on a canvas via the card's inline **Transform**
  controls.
- Stay clean: only that window's contents are shown, even if you switch apps.

## When to use it instead of screen capture

| Use **Window / Tab** when… | Use [Screen Capture](./screen-capture) when… |
|---|---|
| You want only one app visible. | You want the whole desktop. |
| You need to keep working in other windows off‑air. | You're presenting everything on a display. |

> On Linux, window capture uses the system's screen‑sharing picker, so you'll
> choose the window (and may grant permission) the first time.
