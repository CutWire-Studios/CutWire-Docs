# Recording

CutWire Prism can record your show to disk while you run it — the program mix and, where
available, individual streams — with timestamped markers you drop on the fly.

## The Recording Panel

![Recording panel](./assets/recording-panel.avif)

Open it from **View → Recording Panel…**. It's a modeless panel (it stays open
alongside the main window) where each recordable stream has its own row with a
running timer and a **start/stop** button — so you can record streams
independently.

| Control | What it does |
|---|---|
| **Output folder** | Where recordings are saved. Type a path or **Browse** to pick one. |
| **Per‑stream toggle** | Start or stop recording that stream. Each runs on its own. |
| **Timer** | Elapsed recording time for that stream. |

The output folder is remembered between sessions.

## Markers

While recording you can timestamp moments — a goal, a key speech, the start of a
song — so you can find them again in the footage:

- **View → Drop Marker** (or **Ctrl+M**) prompts for a label and stamps it into
  the active recording at the current time.
- CutWire Prism also drops automatic markers when you fire a new clip to a deck, noting
  which clip went live.

## Tips

- Set the **output folder** before the show and confirm it has enough free space.
- Use **Ctrl+M** liberally during the event — labelled markers turn hours of
  footage into something you can edit quickly afterwards.
- Recording runs alongside live output, so you can record while sending to a
  projector, NDI, and a [virtual camera](./virtual-camera) at the same time.
