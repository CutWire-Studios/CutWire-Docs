# Getting started

Install SwitchX, load a few sources, and make your first cut.

## Install

Download the build for your platform from
[cutwire.org/switchx](https://cutwire.org/switchx), then launch the app.

## Your first cut

1. Add a source — drop a clip or pick a capture device.
2. Send it to **program** with `1`.
3. Cue a second source to **preview**.
4. Press `Space` to cut between them.

That's the whole loop: trigger, mix, cut, live.
