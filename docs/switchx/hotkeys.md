# Hotkeys

The keys an operator reaches for mid-show.

| Key | Action |
|---|---|
| `Space` | Cut program ↔ preview |
| `1` – `9` | Trigger source to program |
| `Esc` | Clear preview |
| `T` | Toggle the crossfade T-bar |

Hotkeys are remappable in **Settings → Controls**.
