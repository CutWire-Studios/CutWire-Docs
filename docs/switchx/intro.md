# SwitchX

**Trigger. Mix. Create. Live.**

A live media console for triggering clips, mixing sources, and running shows.
Built to perform, not to configure.

These docs cover everything an operator needs to run SwitchX — from first
install to advanced show setups.

## Start here

- **[Getting started](./getting-started)** — install SwitchX and run your first cut.
- **[Hotkeys](./hotkeys)** — the keys you'll actually press during a show.
